# Battery_RUL_Thesis
Πτυχιακή εργασία: Μελέτη και πρόβλεψη κύκλου ζωής μπαταριών με ανάλυση ανοικτών δεδομένων και μεθόδους Machine Learning. Περιλαμβάνει database, Python scripts, Jupyter notebooks, γραφήματα και μοντέλα πρόβλεψης Remaining Useful Life (RUL). Στόχος: εφαρμογές σε ηλεκτρικά οχήματα, ενεργειακά συστήματα και data centers.
