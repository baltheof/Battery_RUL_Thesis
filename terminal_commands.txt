============================================================
           GIT WORKFLOW - ΟΔΗΓΟΣ ΕΠΙΒΙΩΣΗΣ
============================================================

1. ΞΕΚΙΝΗΜΑ ΝΕΑΣ ΕΡΓΑΣΙΑΣ (NEW BRANCH)
------------------------------------------------------------
ΣΚΟΠΟΣ: Δημιουργώ έναν νέο "δρόμο" για να μην χαλάσω το main.

> git checkout -b ONOMA_BRANCH

------------------------------------------------------------

2. ΑΠΟΘΗΚΕΥΣΗ ΑΛΛΑΓΩΝ (COMMIT)
------------------------------------------------------------
ΣΚΟΠΟΣ: "Κλειδώνω" τις αλλαγές που έκανα στον κώδικα.

> git add .
> git commit -m "ΕΔΩ ΓΡΑΦΩ ΤΙ ΑΛΛΑΞΑ"

------------------------------------------------------------

3. ΑΝΕΒΑΣΜΑ ΣΤΟ GITHUB (PUSH)
------------------------------------------------------------
ΣΚΟΠΟΣ: Στέλνω τη δουλειά μου online.

> git push --set-upstream origin ONOMA_BRANCH
(Σημείωση: Την παραπάνω εντολή τη δίνεις ΜΟΝΟ την 1η φορά)

------------------------------------------------------------

4. ΕΝΩΣΗ ΜΕ ΤΟ MAIN (MERGE)
------------------------------------------------------------
ΣΚΟΠΟΣ: Αφού τελείωσα, φέρνω τη δουλειά μου πίσω στο main.

1. Πηγαίνω στο main:
   > git checkout main

2. Φέρνω αλλαγές από το Cloud:
   > git pull origin main

3. Ενώνω το branch μου:
   > git merge ONOMA_BRANCH

4. Ενημερώνω το GitHub:
   > git push origin main

------------------------------------------------------------

5. ΠΩΣ ΝΑ ΒΓΩ ΑΠΟ ΤΟΝ VIM (SOS)
------------------------------------------------------------
ΣΚΟΠΟΣ: Αν κολλήσω στη μαύρη οθόνη με το "Attention".

1. Πάτα το πλήκτρο [Esc]
2. Γράψε με το πληκτρολόγιο: :q!
3. Πάτα [Enter]

============================================================
