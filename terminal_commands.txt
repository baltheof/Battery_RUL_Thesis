

✅ ΒΗΜΑ 1: ΠΡΟΕΤΟΙΜΑΣΙΑ (ΕΓΙΝΕ ΗΔΗ)

Εντολή: git add .

Τι κάνει: Εντοπίζει τις αλλαγές. Αυτό το τρέξαμε ήδη στο προηγούμενο βήμα, γι' αυτό το τερματικό σου έδειξε τα αρχεία με πράσινο χρώμα. Είναι ήδη στην αίθουσα αναμονής!

>> git status

📦 ΒΗΜΑ 2: ΠΑΚΕΤΑΡΙΣΜΑ (ΤΟ ΕΠΟΜΕΝΟ ΒΗΜΑ ΣΟΥ)

Εντολή: git commit -m "Πρόσθεσα τον φάκελο docs με τις σημειώσεις"

Τι κάνει: «Κλειδώνει» και αποθηκεύει επίσημα αυτές τις αλλαγές στο ιστορικό του υπολογιστή σου, δίνοντάς τους μια περιγραφή (αυτή που είναι μέσα στα εισαγωγικά).

🚀 ΒΗΜΑ 3: ΑΠΟΣΤΟΛΗ (ΤΟ ΤΕΛΙΚΟ ΣΟΥ ΒΗΜΑ)

Εντολή: git push

Τι κάνει: Στέλνει το έτοιμο πακέτο στο ίντερνετ, για να εμφανιστούν επιτέλους οι φάκελοι στη σελίδα σου στο GitHub.
